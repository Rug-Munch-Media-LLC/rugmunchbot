# Competitor parity — seven bots, 2026-10-25

Scope: Mugetsu (`@the_mugetsu_bot`), Phanes (`@Phanes_bot`), Skeleton
(`@SkeletonPriceBot`), Heimdall (`@heimdall_odintools_bot`), PIRBView
(`@PIRBViewBot` / `@PIRBViewPROBot`), TrenchRadar (`@TrenchRadarBot`, trench.bot),
DevsNightmare (`@soldevnightmarebot`, `@devsnightmareprobot` / REKT).

Baseline: `rugmunchbot` (`COMMANDS.md`, 100 registered / 51 advertised).
Method: **public vendor material only** — docs sites, bot pages, public channel
posts, public X profiles, read 2026-10-25 (Phanes/Mugetsu/TrenchRadar/
DevsNightmare) or 2026-10-24 (Skeleton/Heimdall/PIRBView, see
`parity-2026-10-24` material in `bot-parity.md`). No claim is inferred from a
screenshot caption; `UNVERIFIED` means "not stated in any source we read", **not**
a claim of absence. No proprietary code was copied — commands and behaviour
descriptions only.

Provenance for every row: `data/competitors/sources.json`.

## 4. Verdict per axis

- **Beats them:** scan depth and evidence discipline (`/scan`, `/deepscan`, `/wallet`,
  `/trace`), user-owned price alerts, moderation breadth except notes/federations,
  cross-chain and DeFi/polymarket surfaces nobody else documents.
- **Lacks (highest impact, in order):** call tracking + leaderboard > bundle/cluster
  view > fresh-wallet and dev-allocation commands > shareable PnL cards > filter
  builder with backtesting > notes/federations for moderation > `/digest`.
- **Deliberately not cloned:** TrenchRadar's paid filter/backtest engine and
  DevsNightmare's bundling tooling are execution products; we do intelligence and
  safety, not trade execution or bundling.

## 5. Shipped in this branch

`/call`, `/calls`, `/lb`, `/fc` — group call tracking built on the bot's existing
sqlite layer (`src/rugmunchbot/calltrack/`), first-caller-wins, chat-scoped,
counts only (no invented returns). Tests: `tests/test_calltrack_store.py`,
`tests/test_calltrack_render.py`.

Remaining gaps are specified, not silently dropped — see `bot-beyond.md` P0/P1
items and the "Lacks" list above.
