
re-read and its row + `accessed` date updated — a claim is never kept stale.

## Ingest into ContextCrypto / RugBrain

The corpus owner is the `contextcrypto` repo; this repo only ships the source
documents and the manifest. To land them in the retrieval corpus, add one local
docs target on Talos (contextcrypto repo, its own commit):

```yaml
# contextcrypto/docs-registry.yaml  (illustrative; verify the schema before use)
- id: competitors-rugmunchbot
  kind: local
  source: /srv/work/wt/bot-compete/docs/competitors
  license: internal-only, facts-only, no redistribution
```

then run, from `/srv/work/repos/contextcrypto`:

```bash
.venv/bin/python -m scripts.contextcrypto_ingest_docs --only competitors-rugmunchbot --dry-run
.venv/bin/python -m scripts.contextcrypto_ingest_docs --only competitors-rugmunchbot
```
